# Built-in Streamline icons

Ardo bundles 41 [Streamline Core Line](https://www.streamlinehq.com/icons/core-line) icons: 20 section icons for the sidebar tabs (`src/ui/section-icons.tsx`, with source SVGs in [`nav-icons/`](https://github.com/sebastian-software/ardo/tree/main/nav-icons)) and 21 chrome icons (`src/ui/chrome-icons.tsx`, with source SVGs in [`chrome-icons/`](https://github.com/sebastian-software/ardo/tree/main/chrome-icons)). The breadcrumb separator reuses the chevron, so the 22 chrome roles use 21 distinct icons.
