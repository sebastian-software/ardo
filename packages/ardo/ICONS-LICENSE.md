# Built-in Streamline icons

Ardo bundles 65 [Streamline Core Line](https://www.streamlinehq.com/icons/core-line) icons as React components: 20 section icons for the sidebar tabs, 21 chrome icons for the rest of the UI, and 24 additional content motifs. A selection of 50 components is available through `ardo/icons` for Ardo documentation content. They live in `src/ui/icons/sections/`, `src/ui/icons/chrome/`, and `src/ui/icons/content/` and are compiled into `dist`; the package ships no separate SVG files. [`src/ui/icons/README.md`](https://github.com/sebastian-software/ardo/blob/main/packages/ardo/src/ui/icons/README.md) lists which Streamline icon each one is.
