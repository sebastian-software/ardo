# Built-in icons

Ardo draws its own UI with [Streamline Core Line](https://www.streamlinehq.com/icons/core-line) icons: 20 section icons on the sidebar tabs (`sections/`, used through `../section-icons.tsx`) and 21 chrome icons for the header, sidebar, callouts, code blocks and page navigation (`chrome/`, used through `../chrome-icons.tsx`). All of them sit on Core's 14 × 14 grid with a 1 px stroke and `currentColor`.

The components in `sections/` and `chrome/` are generated by [SVGR](https://react-svgr.com). Don't edit them by hand. The source SVGs aren't part of the repository or the npm package; this README records which Streamline icon each one is, so they can be exported again.

Storybook shows every icon at its real size in the **Icons** stories.

Not to be confused with `src/icons`, which re-exports Lucide for authors' own content.

## Change or add an icon

1. Export the icon from the full Core Line set at 14 px with an editable stroke, as SVG.
2. Save it under `packages/ardo/.icon-sources/sections/` or `packages/ardo/.icon-sources/chrome/`, named after its role (for example `light-theme.svg`). That folder is git-ignored. It needs every icon of its set, because SVGR rewrites the set's `index.ts`.
3. Run `pnpm --filter ardo icons:generate`. The SVGR and SVGO settings live under `svgr` in `packages/ardo/package.json`.
4. Map a new component in `../section-icons.tsx` or `../chrome-icons.tsx`, update the tables below, and keep `packages/ardo/ICONS-LICENSE.md` in sync.
