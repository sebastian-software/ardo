# Getting Started

This example demonstrates how to use Ardo to document a TypeScript library with automatic API reference generation through native TypeScript and OXC.

## How It Works

1. Library source code lives in `src/index.ts`
2. The `api` option in `vite.config.ts` enables checked declaration generation in memory
3. Ardo reads the declarations and generates Markdown files into `app/routes/api-reference/`
4. Ardo's route integration picks them up automatically

The same integration updates API documentation during development.

## Project Structure

```
examples/library/
├── src/
│   └── index.ts              # Library source code
├── app/
│   ├── routes/
│   │   ├── home.tsx
│   │   ├── guide/
│   │   │   └── getting-started.mdx
│   │   └── api-reference/    # Generated by the native API integration
│   ├── root.tsx
│   ├── entry.client.tsx
│   └── entry.server.tsx
├── prebuild-declarations.mjs # Optional programmatic generation example
├── tsconfig.api.json         # Public API compiler configuration
├── vite.config.ts
└── package.json
```

## Running Locally

After building Ardo at the repository root, start the dev server normally.
The Vite integration generates the API reference and watches source changes:

```bash
pnpm dev
```

## Building for Production

Ardo's build command generates the API reference before route discovery:

```bash
pnpm build
```

This executes `ardo build`; no separate prebuild step is required.

## Adding Your Own Library

To adapt this example for your own library:

1. Replace the contents of `src/index.ts` with your library code
2. Update `tsconfig.api.json` if your entry points differ
3. Adjust the `api` options in `vite.config.ts` for your entry points and output directory
