# Getting Started

Welcome to the **Ardo Basic Example**. Start with Markdown pages and a small React component. Add optional API documentation, external content, or deployment settings to this same setup when needed.

## What's Included

This example shows:

- Markdown content with frontmatter
- Automatic route generation
- Built-in search
- Dark mode support
- Static pre-rendering, one HTML file per page
- An interactive counter that demonstrates React interactivity

## Project Structure

```text
examples/basic/
├── app/
│   ├── Counter.tsx
│   ├── root.tsx
│   ├── routes/
│   │   ├── home.tsx
│   │   └── guide/
│   │       ├── getting-started.mdx
│   │       └── markdown-features.mdx
├── ardo.config.ts
├── tsconfig.json
└── package.json
```

Pages live in `app/routes/`. `app/root.tsx` sets up the header, sidebar, and footer, and Ardo
provides the HTML shell, the route table, and the entry that hydrates each page. The example's
`ardo.config.ts` sets its title and description; Ardo can also run without this optional file.

## Running Locally

```bash
pnpm dev
```

## Building for Production

```bash
pnpm build
```

The output will be in `build/client/`, ready for your static hosting provider.
