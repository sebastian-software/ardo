# Getting Started

Welcome to the **Ardo Basic Example**. Start with Markdown pages and a small React component. Add optional API documentation, external content, or deployment settings to this same setup when needed.

## What's Included

This example shows:

- Markdown content with frontmatter
- Automatic route generation
- Built-in search
- Dark mode support
- Static pre-rendering
- An interactive counter that demonstrates React interactivity

## Project Structure

```
examples/basic/
├── app/
│   ├── Counter.tsx
│   ├── entry.server.tsx
│   ├── root.tsx
│   ├── routes/
│   │   ├── home.tsx
│   │   └── guide/
│   │       ├── getting-started.mdx
│   │       └── markdown-features.mdx
├── ardo.config.ts
├── react-router.config.ts
├── tsconfig.json
└── package.json
```

The example's `ardo.config.ts` sets its title and deployment defaults; Ardo can also run
without this optional file. It reexports Ardo's server entry from `app/entry.server.tsx`. React
Router's default client entry handles browser hydration.

## Running Locally

```bash
pnpm dev
```

## Building for Production

```bash
pnpm build
```

The output will be in `build/client/`, ready for your static hosting provider.
