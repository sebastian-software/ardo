# Versions

Ardo publie framework, interface et exécution dans un paquet unique. Cette page distingue fonctions disponibles, expérimentales et prévues. Le [journal des modifications](https://github.com/sebastian-software/ardo/blob/main/packages/ardo/CHANGELOG.md) détaille chaque version.

## Guides de migration {#upgrade-guides}

- [Passer à Ardo 6](/fr/guide/releases/upgrade-to-v6) depuis Ardo 5 : build statique sans React Router et moins de fichiers.
- [Passer à Ardo 5](/fr/guide/releases/upgrade-to-v5) depuis Ardo 4 : Ferromark pour Markdown/MDX et Ferriki pour la coloration.
- [Passer à Ardo 4.0](/fr/guide/releases/upgrade-to-v4) depuis Ardo 3 : URL stables par version majeure.
- [Migrer depuis TypeDoc](/fr/guide/releases/migrate-from-typedoc) : la référence native remplace `typedoc`.

Les agents suivent ces guides via les [Instructions pour agents](/fr/guide/agent-instructions).

## Disponible {#shipped}

Ces fonctions sont disponibles dans la branche actuelle.

| Domaine               | Notes                                                                                                                              |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Build statique        | Vite avec HTML par page, routes par fichiers et sans routeur client.                                                               |
| Markdown et MDX       | Markdown, MDX, GFM, frontmatter, sommaire et composants intégrés.                                                                  |
| Coloration syntaxique | Ferriki au build pour le code Markdown et les `CodeBlock` statiques.                                                               |
| Recherche             | Données générées et interface intégrée.                                                                                            |
| Référence API native  | API TypeScript via `api` dans `ardo.config.ts`.                                                                                    |
| Collections           | Fichiers locaux validés par schéma, routes et données typées pour React.                                                           |
| Métadonnées sociales  | URL canoniques, Open Graph et Twitter pour Markdown.                                                                               |
| Sorties SEO           | Sitemap, robots, textes LLM, liens et redirections.                                                                                |
| Couleurs de thème     | Teintes de marque, accent et neutre via la prop `theme` d’`ArdoRoot` ou CSS.                                                       |
| Composants            | Encadrés, badges, cartes, onglets, accordéons, étapes, code, icônes, hero et fonctionnalités : [Composants](/fr/guide/components). |

## Expérimental {#experimental}

Ces domaines fonctionnent, mais leur API ou maintenance peut encore évoluer.

| Domaine                  | Notes                                                                                                                                                             |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| SDK du compilateur natif | TypeScript 7.1 nightly épinglé ; compatibilité et stabilité à surveiller.                                                                                         |
| Tokens de thème          | Variables CSS et tokens Vanilla Extract publics ; les autres API peuvent évoluer.                                                                                 |
| Versions documentaires   | Dossiers statiques, redirections racine, `versions.json`, sélecteur et bandeau d’ancienne version.                                                                |
| i18n statique            | Arbres complets, recherche et interface localisées, liens alternatifs et rejet des traductions absentes : [Internationalisation](/fr/guide/internationalization). |
| OpenAPI statique         | Références locales OpenAPI 3.0/3.1 JSON/YAML ; pas de playground interactif.                                                                                      |

## Non prévu {#not-planned}

Ardo se concentre sur une approche précise de la documentation.

| Domaine                             | Raison                                                                                                     |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Édition hébergée                    | Ardo reste lié au dépôt et auto-hébergé. Choisissez une plateforme hébergée pour ce type de collaboration. |
| Produit analytics intégré           | Les sites statiques intègrent directement des prestataires ; Ardo n’a pas à stocker les événements.        |
| Site de prose au JavaScript minimal | La réutilisation React prime. Astro, VitePress ou Starlight peuvent mieux convenir à la prose seule.       |
| Exemples TypeScript au survol       | Les indications Twoslash demandent beaucoup de maintenance et d’outillage.                                 |
| Playgrounds intégrés                | Les éditeurs Sandpack ne cadrent pas avec la sortie statique et les petits bundles.                        |
