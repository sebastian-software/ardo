# Migrer vers Ardo 5

Ardo 5 utilise Ferromark pour Markdown et MDX, avec la coloration native Ferriki. Ferromark produit du JSX indépendant du framework ; Ardo fournit les liaisons React, mises en page, contexte de page et métadonnées de routes. Votre configuration de routes React reste le point d’intégration.

## Exécution et installation {#runtime-and-installation}

Utilisez Node.js 22.13 ou ultérieur sur Linux ou Windows x64/arm64, ou macOS Apple Silicon. Gardez les dépendances optionnelles activées pour installer les binaires natifs correspondants. Aucun moteur JavaScript de remplacement n’est fourni.

Les grammaires et thèmes standards Ferriki sont téléchargés puis mis en cache à la première utilisation. Remplissez le cache lors d’un build avec accès réseau, conservez-le en CI et configurez les exécutions hors ligne avec :

```sh
FERRIKI_CACHE_DIR=/path/to/persisted/ferriki-cache
FERRIKI_ASSETS_REMOTE=0
```

Consultez les [ressources standards de Ferriki](https://github.com/sebastian-software/ferriki/blob/main/docs/ferriki-api.md#standard-assets) pour les miroirs et le comportement du cache.

## Configuration Markdown {#markdown-configuration}

Retirez `markdown.remarkPlugins`, `markdown.rehypePlugins` et les personnalisations recma. Configurez directement les options de syntaxe Ferromark et les transformations natives ordonnées :

```ts
markdown: {
  theme: { light: "github-light-default", dark: "github-dark-default" },
  lineNumbers: true,
  headingAttributes: true,
  passes: [
    { kind: "typography", language: "en" },
    { kind: "emojiShortcodes" },
  ],
}
```

Les tableaux GFM, le texte barré, les listes de tâches, liens automatiques, notes de bas de page et encadrés restent activés par défaut. Utilisez le frontmatter YAML. Les imports MDX, exports nommés, expressions, remplacements de composants et export de mise en page par défaut restent pris en charge. Les blocs `import` et `export` sont du JavaScript ; une mise en page par défaut remplace le wrapper Ardo. Voir les [modules MDX](/fr/guide/markdown). Ferromark rend titres de blocs, libellés, lignes surlignées et numéros de ligne avec Ferriki. L’usage statique d’`ArdoCodeBlock` en TSX passe par la précompilation Ferriki directe d’Ardo.

## Liens des titres {#heading-links}

Ferromark détermine les identifiants de titres. La ponctuation sépare les mots : `What's included?` devient `what-s-included`. Les doublons reçoivent des suffixes numériques. Un premier H1 identique au titre du frontmatter est omis et ne réserve pas d’identifiant. Les titres Setext et le Markdown dans JSX utilisent le même sommaire que les titres ATX.

Actualisez les liens de fragments écrits à la main si un identifiant change. Titres rendus, sommaire, recherche et vérification des liens partagent les identifiants natifs. Un build de production avec validation des liens repère les fragments périmés.

## API autonomes supprimées {#removed-standalone-apis}

`transformMarkdown`, `transformMarkdownToReact`, `loadDoc` et `loadAllDocs` ont été supprimés. Compilez le HTML autonome directement avec Ferromark. Pour les routes, utilisez l’intégration Vite et les hooks publics d’Ardo.
