# Composants

Ardo fournit encadrés, badges, cartes, onglets, accordéons, étapes, blocs de code, icônes et éléments de page d’accueil. Ils suivent les thèmes clair et sombre et fonctionnent au clavier. Les exemples utilisent la véritable mise en page : changez le thème ou la taille de fenêtre pour les examiner.

En MDX, utilisez `Tip`, `Card` et `Tabs` sans import. En TSX, importez `ArdoTip`, `ArdoCard` et `ArdoTabs` depuis `ardo/ui`. Les composants de page d’accueil demandent un import explicite dans les deux formats.

## Encadrés {#callouts}

Choisissez la variante adaptée. Les cinq utilisent les tokens du thème et acceptent un titre personnalisé.

<Tip title="Regrouper les instructions liées">Placez les conseils courts à côté de la tâche.</Tip>
<Info title="Sortie statique">Ardo prérend les routes pendant le build de production.</Info>
<Note title="Configuration facultative">
  Le frontmatter peut remplacer le titre et l’ordre dans la barre latérale.
</Note>
<Warning title="Vérifier la destination">
  Vérifiez le chemin de base avant de publier un site versionné.
</Warning>
<Danger title="Exemple destructif">
  Exportez vos données avant de remplacer un dossier contenant du travail à conserver.
</Danger>

```mdx
<Tip title="Keep related instructions together">Put the guidance next to the task.</Tip>
```

Ces variantes existent aussi comme [alertes GitHub](/fr/guide/markdown#callouts) en Markdown simple.

## Badges {#badges}

Les badges ajoutent un statut compact dans le texte : <Badge>Nouveau</Badge> <Badge variant="success">Stable</Badge> <Badge variant="warning">Aperçu</Badge> <Badge variant="danger">Obsolète</Badge> <Badge variant="info">Référence</Badge> <Badge icon="✦">Avec icône</Badge>.

```mdx
<Badge variant="success">Stable</Badge>
<Badge icon="✦">With icon</Badge>
```

## Cartes {#cards}

Utilisez les cartes liées pour naviguer et les cartes statiques pour résumer. La grille passe à une colonne sur petit écran.

<CardGroup cols={2}>
  <Card title="Bien démarrer" icon="Rocket" href="/fr/guide/getting-started">
    Créez votre documentation avec un assistant ou manuellement.
  </Card>
  <Card title="Configuration" icon="Settings" href="/fr/guide/configuration">
    Configurez routes, référence API, métadonnées et sortie.
  </Card>
  <Card title="Composants locaux" icon="Code">
    Importez les composants du projet ou d’un paquet installé.
  </Card>
  <Card
    title="Code source"
    icon={<Github size={20} />}
    href="https://github.com/sebastian-software/ardo"
  >
    Examinez l’implémentation et contribuez sur GitHub.
  </Card>
</CardGroup>

```mdx
<CardGroup cols={2}>
  <Card title="Getting Started" icon="Rocket" href="/guide/getting-started">
    Set up a documentation site.
  </Card>
  <Card title="Local components" icon="Code">
    Import components into your MDX routes.
  </Card>
</CardGroup>
```

| Composant   | Prop        | Type                  | Usage                                                                |
| ----------- | ----------- | --------------------- | -------------------------------------------------------------------- |
| `CardGroup` | `cols`      | `1 \| 2 \| 3 \| 4`    | Nombre de colonnes sur grand écran. Défaut : `2`.                    |
| `CardGroup` | `children`  | `ReactNode`           | Cartes de la grille responsive.                                      |
| `Card`      | `title`     | `string`              | Titre obligatoire.                                                   |
| `Card`      | `href`      | `string`              | Destination interne ou externe facultative. Rend la carte cliquable. |
| `Card`      | `icon`      | `string \| ReactNode` | Nom d’icône enregistré ou contenu React.                             |
| `Card`      | `children`  | `ReactNode`           | Contenu de la carte.                                                 |
| `Card`      | `className` | `string`              | Classe CSS supplémentaire.                                           |

## Onglets {#tabs}

Les onglets conviennent aux choix équivalents, tels les gestionnaires de paquets. Sélectionnez-en un ou utilisez Gauche, Droite, Début et Fin après l’avoir ciblé.

      <Tab value="pnpm">pnpm</Tab>
      <Tab value="npm">npm</Tab>
      <Tab value="yarn">yarn</Tab>
    </TabList>
    <TabPanels>
      <TabPanel value="pnpm">
        <CodeBlock language="bash" code="pnpm add ardo" />
      </TabPanel>
      <TabPanel value="npm">
        <CodeBlock language="bash" code="npm install ardo" />
      </TabPanel>
      <TabPanel value="yarn">
        <CodeBlock language="bash" code="yarn add ardo" />
      </TabPanel>
    </TabPanels>
  </Tabs>
</GalleryPreview>

```mdx
<Tabs defaultValue="pnpm">
  <TabList>
    <Tab value="pnpm">pnpm</Tab>
    <Tab value="npm">npm</Tab>
  </TabList>
  <TabPanels>
    <TabPanel value="pnpm">pnpm add ardo</TabPanel>
    <TabPanel value="npm">npm install ardo</TabPanel>
  </TabPanels>
</Tabs>
```

Si vos composants créent les onglets en interne, définissez `defaultValue` sur `Tabs` et des valeurs `value` explicites correspondantes sur chaque paire.

| Composant  | Prop           | Type        | Usage                                                                    |
| ---------- | -------------- | ----------- | ------------------------------------------------------------------------ |
| `Tabs`     | `defaultValue` | `string`    | Onglet initial. Défaut : le premier.                                     |
| `Tabs`     | `children`     | `ReactNode` | `TabList` et `TabPanels` correspondants.                                 |
| `Tab`      | `value`        | `string`    | Valeur stable associée au `TabPanel`. Facultative si l’ordre est stable. |
| `Tab`      | `children`     | `ReactNode` | Libellé de l’onglet.                                                     |
| `TabPanel` | `value`        | `string`    | Valeur du contenu. Facultative si l’ordre correspond.                    |
| `TabPanel` | `children`     | `ReactNode` | Contenu du panneau.                                                      |

## Blocs de code {#code-blocks}

Le bouton de copie prend le code sans titre ni numéros de ligne. Les blocs Markdown sont colorés au build ; `CodeBlock` accepte aussi directement une chaîne.

<GalleryPreview id="gallery-code" label="Exemple de code">
  <CodeBlock language="bash" title="terminal" code="pnpm add ardo" />
</GalleryPreview>

```mdx
<CodeBlock language="bash" title="terminal" code="pnpm add ardo" />
```

`CodeGroup` regroupe les extraits liés avec leur nom de fichier :

<GalleryPreview id="gallery-code-group" label="Exemple de groupe de code">
  <CodeGroup labels="Configuration,Route d’accueil">
    <CodeBlock
      language="typescript"
      title="ardo.config.ts"
      code={
        'import { defineArdoConfig } from "ardo/config"\n\nexport default defineArdoConfig({ title: "My docs" })'
      }
    />
    <CodeBlock
      language="markdown"
      title="app/routes/home.md"
      code={"# Welcome\n\nStart with your first guide."}
    />
  </CodeGroup>
</GalleryPreview>

Les blocs Markdown acceptent titres, lignes mises en évidence, numéros et retours à la ligne pour les prompts ; voir [Coloration syntaxique](/fr/guide/markdown#syntax-highlighting).

### Dans les routes TSX {#in-tsx-routes}

Utilisez `ArdoCodeBlock` directement dans les routes `.tsx`. Écrivez le code comme contenu enfant, sans littéral de gabarit ni échappement particulier :

```tsx
import { ArdoCodeBlock } from "ardo/ui"

export default function MyPage() {
  return (
    <ArdoCodeBlock language="tsx">
      export function Hello() {
        return <div>Hello world!</div>
      }
    </ArdoCodeBlock>
  )
}
```

Le plugin `ardo:codeblock-highlight` traite ArdoCodeBlock **avant l’analyse JSX**. Le contenu accepte donc `<`, `{`, `>` et toute autre syntaxe. L’indentation commune est retirée.

La prop `code` et les littéraux de gabarit fonctionnent aussi :

```tsx
<ArdoCodeBlock code="const x = 42" language="typescript" />
```

Si `language` est dynamique, la coloration au build est ignorée et le code s’affiche en texte brut.

## Icônes {#icons}

Ardo inclut 50 icônes [Streamline Core Line](https://streamlinehq.com/icons/core-line). Elles partagent la grille 14×14, les traits arrondis et `currentColor` des contrôles de navigation.

Les icônes enregistrées apparaissent en 14 et 28 pixels. Utilisez leur nom avec `Icon` ou importez le composant depuis `ardo/icons`.

<GalleryIcons />

### Utiliser dans MDX {#use-in-mdx}

Les 50 icônes Core sont disponibles sans import ni enregistrement :

```mdx
<Icon name="Zap" size={20} />
<Card title="Deploy your site" icon="Rocket">
  Build the static output and publish it to your host.
</Card>
```

| Composant | Prop      | Type                           | Usage                                   |
| --------- | --------- | ------------------------------ | --------------------------------------- |
| `Icon`    | `name`    | `string`                       | Nom d’icône enregistré.                 |
| `Icon`    | `size`    | `number`                       | Taille d’affichage facultative.         |
| `Icon`    | SVG props | `SVGAttributes<SVGSVGElement>` | Transmises au composant SVG enregistré. |

### Utiliser dans React {#use-in-react}

```tsx
import { BookOpen, Rocket, ShieldCheck } from "ardo/icons"

<BookOpen size={20} />
<Rocket size={28} className="launch-icon" />
<ShieldCheck size={20} aria-label="Security checks passed" />
```

La taille par défaut est 24 px. `size` accepte un nombre ou une longueur CSS ; vous pouvez aussi définir `width` et `height`. Les icônes héritent de la couleur du texte et sont décoratives par défaut. Ajoutez `aria-label` ou `aria-labelledby` si elles transmettent une information sans texte.

`ArdoIcon` affiche une icône enregistrée par son nom, par exemple dans un lien :

```tsx
import { ArdoIcon, ArdoLink } from "ardo/ui"

export function LaunchLink() {
  return (
    <ArdoLink to="/guide/getting-started">
      <ArdoIcon name="Rocket" aria-hidden /> Get started
    </ArdoLink>
  )
}
```

### Ajouter ou remplacer des icônes {#add-or-override-icons}

Enregistrez d’autres composants SVG React et icônes de marque avec `registerIcons()` dans `app/root.tsx` :

```tsx
import { Github } from "ardo/icons"
import { registerIcons } from "ardo/ui"

registerIcons({ Github })
```

Utilisez ensuite `<Icon name="Github" />` dans MDX. Un nom existant remplace son icône intégrée. Déclarez les autres bibliothèques comme dépendances directes et importez-les dans le module d’enregistrement.

`getRegisteredIconNames()` renvoie les noms intégrés et personnalisés pour valider la configuration.

## Mise en page et navigation {#layout-and-navigation}

Cette page montre la véritable mise en page : en-tête, sections, barre latérale, fil d’Ariane, article, sommaire, actions et pied de page. Sur petit écran, ouvrez menu et sommaire. Testez la recherche et le thème dans l’en-tête.

[Mise en page et navigation](/fr/guide/layout-and-navigation) décrit la composition et [Thèmes](/fr/guide/theming) la palette. Les exemples héritent des réglages sans thème d’aperçu distinct.
