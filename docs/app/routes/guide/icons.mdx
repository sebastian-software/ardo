# Icons

## Use in React

```tsx
import { BookOpen, Rocket, ShieldCheck } from "ardo/icons"

<BookOpen size={20} />
<Rocket size={28} className="launch-icon" />
<ShieldCheck size={20} aria-label="Security checks passed" />
```

The default size is 24 px. Set `size` to a number or CSS length, or pass native `width` and `height` attributes. Icons inherit the surrounding text color. They are decorative by default; supply `aria-label` or `aria-labelledby` when the icon conveys information without accompanying text.

## Use in MDX

All 50 Core icons are available automatically. Use their names directly without imports or a registration call:

```mdx
<Icon name="Zap" size={20} />
<Card title="Deploy your site" icon="Rocket">
  Build the static output and publish it to your host.
</Card>
```

## Add or override icons

Use `registerIcons()` in `app/root.tsx` to add other React SVG components or brand icons:

```tsx
import { Github } from "ardo/icons"
import { registerIcons } from "ardo/ui"

registerIcons({ Github })
```

Then use `<Icon name="Github" />` in MDX. Registering an existing name overrides its built-in component. For icons from another library, declare that library as a direct dependency and import its components in your registration module.

## Brand icons and usage terms

`Github`, `Linkedin`, `Npm`, `Twitter`, and `Youtube` are also available from `ardo/icons`, with matching `Icon` aliases such as `GithubIcon`. Brand marks retain their own proportions and colors follow `currentColor`.
