# create-ardo Lifecycle

Ardo 6 retires `create-ardo`. Use [Agent Instructions](/guide/agent-instructions) for a new site, adoption into an existing repository, or an upgrade. The instructions use [a tested Basic example](/guide/reference-projects) matched to the installed Ardo release.

## Current decision

The CLI package, templates, upgrade flow, and linked release configuration are removed. Ardo's plugins and builds continue to validate configuration and generated output. A [manual installation guide](/guide/getting-started#manual-installation) remains available for setup without an agent.

## Existing Projects

Projects created by older starters remain ordinary Ardo applications. Removing the starter does not require replacing their application shell or authored content. Use the versioned instructions when upgrading the framework. Published `create-ardo` 5.x releases are historical starters and do not support Ardo 6.

## Revisit Criteria

Reconsider a generator only when repeated real setup failures cannot be addressed through instructions, the executable example, or framework validation.
