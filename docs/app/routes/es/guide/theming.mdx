# Personalización visual

El tema Ardo está completo. Personalízalo donde compones el sitio: en `app/root.tsx`, con props React y archivos importados. Empieza por unos tonos:

1. **Prop `theme`:** tonos, saturación, avisos, fuentes y tokens.
2. **Logotipo y favicon:** archivos importados con huellas de Vite.
3. **Variables CSS y Vanilla Extract:** tus estilos con tokens Ardo.
4. **Tailwind CSS:** clases de utilidad para páginas y componentes.

Para sustituir cabecera, barra lateral o pie, consulta [Diseño y navegación](/es/guide/layout-and-navigation#replace-parts-of-the-chrome).

## Colores, logotipo y favicon {#colors-logo-and-favicon}

**`app/root.tsx`**:

```tsx
import { ArdoRoot } from "ardo/ui"

import logo from "./assets/logo.svg"

export default function Root() {
  return (
    <ArdoRoot theme={{ color: "blue", accent: "teal", neutral: "slate" }} logo={logo} icon={logo} />
  )
}
```

`theme` define tres tonos: `color` para enlaces, botones y foco, `accent` para acentos secundarios y código, y `neutral` para fondos, bordes, texto y navegación. Ardo deriva los demás colores claros y oscuros.

`logo` e `icon` reciben archivos importados. Vite añade huellas a las URL para renovar la caché al desplegar. Aquí el logotipo sirve de favicon; para una marca textual, pasa una imagen cuadrada a `icon`.

- **Logotipos claro y oscuro:** `logo={{ light: logoLight, dark: logoDark }}`.
- **Inicio de iOS:** `appleTouchIcon` recibe un PNG de 180×180.
- **Sin `icon`:** Ardo enlaza sus iconos de búho. Los accesos directos a `/favicon.ico` también reciben el búho, salvo archivo propio en `public/`.

La configuración no contiene colores ni recursos, sino datos del build: título, base, versiones y referencia API.

## Tonos y preajustes {#hues-and-presets}

`color`, `accent` y `neutral` aceptan un preajuste o un ángulo OKLCH de `0` a `360`:

```tsx
<ArdoRoot theme={{ color: 240, accent: 170, neutral: 260 }} />
```

Preajustes: `berry` (predeterminado), `red`, `orange`, `amber`, `green`, `teal`, `blue`, `indigo`, `purple`, `pink`, `slate` y `gray`. `gray` carece de tono y `slate` es azul apagado.

Sin `accent`, Ardo elige un complementario; sin `neutral`, un leve tono de marca. `neutral: "gray"` queda sin tinte.

## Saturación {#saturation}

`chroma` ajusta la saturación. `1` conserva la paleta, valores inferiores la suavizan y `0` vuelve gris el rol. Un número se aplica a `color` y `accent`; un objeto ajusta cada rol, incluido `neutral`:

```tsx
<ArdoRoot
  theme={{
    color: "green",
    accent: "orange",
    neutral: 95,
    chroma: { color: 0.4, accent: 2, neutral: 1.6 },
  }}
/>
```

Por encima de `1`, tonos como el turquesa salen de la gama sRGB. Comprueba el contraste de enlaces al aumentar `color`.

## Colores de avisos {#callout-colors}

Los avisos conservan sus tonos para seguir reconocibles. Si chocan con el acento, ajusta `status`. Ardo deriva texto, fondo y borde para ambos modos:

```tsx
<ArdoRoot theme={{ accent: 38, status: { warning: 72 } }} />
```

`status` admite `tip`, `warning`, `danger`, `info` y `note` como preajuste o tono. Cada preajuste mantiene un contraste de texto mínimo de 4,5:1.

## Fuentes {#fonts}

Carga una fuente como dependencia y nómbrala en `fonts`, por ejemplo con [Fontsource](https://fontsource.org/):

```bash
pnpm add @fontsource-variable/inter
```

```tsx title="app/root.tsx"
import "@fontsource-variable/inter"
import { ArdoRoot } from "ardo/ui"

export default function Root() {
  return <ArdoRoot theme={{ fonts: { body: '"Inter Variable", system-ui, sans-serif' } }} />
}
```

Los títulos siguen `body` salvo ajuste de `heading`. `mono` define la fuente del código.

## Tokens de diseño {#design-tokens}

`tokens` ajusta los tokens para ambos modos. `light` y `dark` los reemplazan por separado, especialmente para colores:

```tsx title="app/root.tsx"
import { ArdoRoot, type ArdoThemeProps } from "ardo/ui"

const theme: ArdoThemeProps = {
  tokens: {
    radius: { sm: "0px", base: "0px", lg: "0px" },
    color: {
      shadowSm: "0 0 0 0 transparent",
      shadowMd: "0 0 0 0 transparent",
      shadowLg: "0 0 0 0 transparent",
    },
  },
  light: { color: { bg: "#fbfbf8", text: "#101010", brand: "#0038ff", brandGradient: "#0038ff" } },
  dark: { color: { bg: "#101010", text: "#fbfbf8" } },
}

export default function Root() {
  return <ArdoRoot theme={theme} />
}
```

TypeScript señala tokens desconocidos y Ardo también los rechaza al renderizar. `shadowSm`, `shadowMd`, `shadowLg` y `codeShadow` son valores `box-shadow` completos. Para no mostrar sombra, usa `0 0 0 0 transparent`: `none` rompe sombras combinadas. `brandGradient` admite un color simple.

La documentación usa así la paleta del búho: oliva, terracota, blanco cálido y mostaza para avisos:

```tsx
const theme: ArdoThemeProps = {
  color: 123,
  accent: 38,
  neutral: 95,
  chroma: { color: 0.4, accent: 2, neutral: 1.6 },
  status: { warning: 72 },
  light: { color: { codeBg: "oklch(0.973 0.006 95)", codeBorder: "oklch(0.9 0.009 95)" } },
  dark: { color: { codeBg: "oklch(0.205 0.01 95)", codeBorder: "oklch(0.31 0.014 95)" } },
}
```

## Raíz propia {#your-own-root}

`ArdoRoot` renderiza el tema automáticamente. Una raíz compuesta con `ArdoProvider` y `ArdoLayout` renderiza `<ArdoTheme>` con las mismas props, pasa `logo` a `ArdoHeader` y el favicon al shell `ArdoRootLayout`:

```tsx title="app/root.tsx"
import type { ReactNode } from "ardo/react"
import { ArdoRootLayout, ArdoTheme } from "ardo/ui"

import icon from "./assets/icon.svg"
import { SiteShell } from "./site-shell"

export function Layout({ children }: { children: ReactNode }) {
  return <ArdoRootLayout icon={icon}>{children}</ArdoRootLayout>
}

export default function Root() {
  return (
    <>
      <ArdoTheme color="blue" neutral="slate" />
      <SiteShell />
    </>
  )
}
```

## Variables CSS {#css-variables}

Cada token es también una variable CSS, como `--ardo-hue-brand` o `--ardo-color-bg`. Tus estilos sin capa prevalecen sobre la capa `ardo`. Un color en `:root` también se aplica en oscuro; limita los colores a su modo:

```css
:root:not(.dark) {
  --ardo-color-bg: oklch(0.99 0.004 95);
}

.dark {
  --ardo-color-bg: oklch(0.17 0.006 95);
}
```

Las variables de tono, saturación, diseño y tipografía funcionan en `:root`. Valores habituales y predeterminados:

```css
:root {
  /* Hues */
  --ardo-hue-brand: 356;
  --ardo-hue-accent: 230;
  --ardo-hue-neutral: 356;
  --ardo-hue-tip: 155;
  --ardo-hue-warning: 45;
  --ardo-hue-danger: 25;
  --ardo-hue-info: 220;
  --ardo-hue-note: 270;

  /* Chroma multipliers: 1 is the default saturation, 0 is gray */
  --ardo-chroma-brand: 1;
  --ardo-chroma-accent: 1;
  --ardo-chroma-neutral: 1;

  /* Layout */
  --ardo-layout-sidebarWidth: 20rem;
  --ardo-layout-tocWidth: 15rem;
  --ardo-layout-contentMaxWidth: 36em; /* em: the measure follows each element's font size */
  --ardo-layout-pageMaxWidth: 69rem; /* header, hero, features, footer on bare pages */
  --ardo-layout-headerHeight: 3.5rem;

  /* Typography */
  --ardo-font-family: system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", ...;
  --ardo-font-familyHeading: var(--ardo-font-family);
  --ardo-font-mono: ui-monospace, SFMono-Regular, ...;
  --ardo-font-lineHeight: 1.65;

  /* Border radius */
  --ardo-radius-sm: 0.25rem;
  --ardo-radius-base: 0.5rem;
  --ardo-radius-lg: 0.75rem;
}
```

## Tokens Vanilla Extract {#vanilla-extract-tokens}

La interfaz usa [Vanilla Extract](https://vanilla-extract.style/). Los tokens tipados de `ardo/theme` aportan autocompletado y errores de compilación para referencias incorrectas.

La CLI incluye el plugin: `.css.ts` funciona sin ajustes Vite adicionales. Instala antes la API de estilos en el paquete:

```bash
pnpm add @vanilla-extract/css
```

### Usar los tokens {#using-tokens-in-your-styles}

Crea un archivo `.css.ts` en el proyecto:

```ts
// styles/custom.css.ts
import { style, globalStyle } from "@vanilla-extract/css"
import { vars } from "ardo/theme"

export const highlight = style({
  background: vars.color.brandSubtle,
  borderLeft: `3px solid ${vars.color.brand}`,
  padding: "16px",
  borderRadius: vars.radius.base,
})

// Override Ardo's default styles
globalStyle(".ardo-content a", {
  color: vars.color.brand,
  textDecoration: "underline",
})
```

### Hojas de estilo y cascada {#stylesheet-ownership-and-cascade}

Ardo carga `ardo/ui/styles.css` después de los imports CSS de la raíz. Contiene interfaz, reset y tema en la capa `ardo`. Los imports de componentes o uno explícito no añaden una segunda copia.

El CSS normal sin capa tiene prioridad sin importar el orden de carga. Puedes sobrescribir `.ardo-footer` directamente. Si usas capas, declara su orden en la primera hoja raíz, por ejemplo `@layer ardo, app;`.

### Selectores estables {#stable-override-hooks}

Las clases generadas son internas. Usa las clases estables para ajustes concretos:

| Región                              | Clases                                                                                                            |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Cabecera y navegación               | `.ardo-header`, `.ardo-nav`, `.ardo-mobile-panel`                                                                 |
| Barra lateral                       | `.ardo-sidebar`, `.ardo-sidebar-tabs`, `.ardo-sidebar-panel`, `.ardo-sidebar-header`, `.ardo-sidebar-nav`         |
| Cuadrícula y panel derecho opcional | `.ardo-doc-page`, `.ardo-page-rail`, `.ardo-page-rail-section`                                                    |
| Artículo e introducción             | `.ardo-content`, `.ardo-content-header`, `.ardo-content-title`, `.ardo-content-description`, `.ardo-content-body` |
| Índice                              | `.ardo-toc`                                                                                                       |
| Bloques de código                   | `.ardo-code-block`, `.ardo-code-title`, `.ardo-code-wrapper`, `.ardo-copy-button`                                 |
| Pie de página                       | `.ardo-footer`                                                                                                    |

Estas clases son puntos de personalización, no otra API. Prioriza tokens y props y usa después los selectores para ajustes propios.

Limita los cambios al wrapper del sitio. Puedes ocultar `.ardo-sidebar-tabs` si tu navegación mantiene todas las secciones accesibles en escritorio y móvil. Pon las variables necesarias para portales del body, como la búsqueda, en el `className` de `ArdoRootLayout`.

### Categorías de tokens {#available-token-categories}

`vars` incluye estas categorías:

- **`vars.color`** — Colores, superficies, texto, bordes, sombras y colores semánticos.
- **`vars.hue`** — Tonos de marca, acento, neutros y avisos.
- **`vars.chroma`** — Factores de saturación de marca, acento y neutros.
- **`vars.layout`** — Anchuras de navegación, índice, contenido y página, altura de cabecera.
- **`vars.transition`** — Transiciones rápidas, normales y lentas.
- **`vars.font`** — Fuentes de texto, títulos y código, tamaño base e interlineado.
- **`vars.fontSize`** — Escala tipográfica de `xs` a `4xl`.
- **`vars.space`** — Escala de espacios de `xs` a `4xl`.
- **`vars.radius`** — Radios `sm`, `base`, `lg`, `xl` y `full`.

## Tailwind CSS {#tailwind-css}

[Tailwind CSS v4](https://tailwindcss.com/) es opcional para tus páginas, ejemplos y MDX. Conserva tu solución de estilos al adoptar Ardo.

Ardo usa Vanilla Extract para su interfaz. Tailwind sirve a tus contenidos: estilos en React sin otro sistema de temas.

### Instalación {#setup}

Instala `tailwindcss` y `@tailwindcss/vite` como dependencias de desarrollo y configura:

1. `@tailwindcss/vite` en los `plugins` de `vite.config.ts`.
2. `tailwindcss` como dependencia de desarrollo.
3. `app/app.css` con capas de tema y utilidades.

```css title="app/app.css"
@layer theme, base, ardo, components, utilities;
@import "tailwindcss/theme.css" layer(theme);
@import "tailwindcss/utilities.css" layer(utilities);

/* Follow Ardo's theme toggle, which sets the .dark class on <html>. */
@custom-variant dark (&:where(.dark, .dark *));
```

Importa el archivo en `app/root.tsx`. Ardo carga su hoja después, así que se aplica este orden. Pon `ardo` antes de `components` y `utilities` para priorizar las utilidades.

La variante `dark:` sigue normalmente al sistema. `@custom-variant` hace que siga al selector Ardo y cambie con el sitio.

### Ejemplos {#examples}

Funciona directamente en cualquier `.mdx`:

```html
  <span className="text-xl">💡</span>
```


### ¿Por qué sin Preflight? {#why-no-preflight}

Ardo aporta estilos base de tipografía, títulos, enlaces, listas y código. El reset Preflight entraría en conflicto con esa apariencia.

Si controlas todos los estilos de un sitio muy personalizado, activa Preflight en `app/app.css`:

```css title="app/app.css"
@layer theme, base, ardo, components, utilities;
@import "tailwindcss/theme.css" layer(theme);
@import "tailwindcss/preflight.css" layer(base);
@import "tailwindcss/utilities.css" layer(utilities);
```

Ardo define explícitamente marcadores, bordes de tablas, código y espacios. El contenido sigue legible con un reset del host. `ardo` va después de `base`, por lo que Preflight no lo anula, y antes de `utilities`, que conserva la prioridad.
