# Actualizar a Ardo 5

Ardo 5 usa Ferromark para Markdown y MDX, con resaltado nativo Ferriki. Ferromark genera JSX independiente del framework; Ardo aporta los enlaces con componentes React, diseños, contexto de página y metadatos de rutas. Tu configuración de rutas React sigue siendo el punto de integración.

## Ejecución e instalación {#runtime-and-installation}

Usa Node.js 22.13 o posterior en Linux o Windows x64/arm64, o macOS Apple Silicon. Mantén las dependencias opcionales activadas para instalar los binarios nativos correspondientes. No hay un motor JavaScript alternativo.

Las gramáticas y temas estándar de Ferriki se descargan y guardan en caché al usarlos por primera vez. Rellena la caché con acceso a red, consérvala en CI y configura las ejecuciones sin conexión con:

```sh
FERRIKI_CACHE_DIR=/path/to/persisted/ferriki-cache
FERRIKI_ASSETS_REMOTE=0
```

Consulta los [recursos estándar de Ferriki](https://github.com/sebastian-software/ferriki/blob/main/docs/ferriki-api.md#standard-assets) para los mirrors y el comportamiento de la caché.

## Configuración Markdown {#markdown-configuration}

Elimina `markdown.remarkPlugins`, `markdown.rehypePlugins` y las personalizaciones recma. Configura directamente las opciones de sintaxis de Ferromark y las transformaciones nativas ordenadas:

```ts
markdown: {
  theme: { light: "github-light-default", dark: "github-dark-default" },
  lineNumbers: true,
  headingAttributes: true,
  passes: [
    { kind: "typography", language: "en" },
    { kind: "emojiShortcodes" },
  ],
}
```

Las tablas GFM, el tachado, listas de tareas, enlaces automáticos, notas al pie y avisos siguen activados por defecto. Usa frontmatter YAML. Se mantienen los imports MDX, exportaciones con nombre, expresiones, sustituciones de componentes y exportación de diseño predeterminado. Los bloques `import` y `export` son JavaScript; un diseño predeterminado sustituye el wrapper de Ardo. Consulta los [módulos MDX](/es/guide/markdown). Ferromark muestra títulos, etiquetas, líneas destacadas y números de línea con Ferriki. El uso estático de `ArdoCodeBlock` en TSX usa la pasada previa directa de Ferriki de Ardo.

## Enlaces de títulos {#heading-links}

Ferromark determina los identificadores de títulos. La puntuación separa palabras: `What's included?` se convierte en `what-s-included`. Los duplicados reciben sufijos numéricos. El primer H1 que coincide con el título del frontmatter se omite y no reserva identificador. Los títulos Setext y el Markdown dentro de JSX comparten índice con los títulos ATX.

Actualiza los enlaces de fragmento escritos a mano cuando cambie un identificador. Los títulos, el índice, la búsqueda y la comprobación de enlaces comparten los identificadores nativos. Ejecuta una compilación de producción con validación de enlaces para detectar fragmentos obsoletos.

## API independientes retiradas {#removed-standalone-apis}

Se han retirado `transformMarkdown`, `transformMarkdownToReact`, `loadDoc` y `loadAllDocs`. Compila HTML independiente directamente con Ferromark. Para las rutas, usa la integración Vite y los hooks públicos de Ardo.
