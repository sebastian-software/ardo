# Componentes

Ardo incluye avisos, insignias, tarjetas, pestañas, acordeones, pasos, bloques de código, iconos y elementos de portada. Siguen los temas claro y oscuro y funcionan con teclado. Los ejemplos usan el diseño real: cambia el tema o el tamaño de ventana para comprobarlos.

En MDX, usa `Tip`, `Card` y `Tabs` sin importarlos. En TSX, importa `ArdoTip`, `ArdoCard` y `ArdoTabs` desde `ardo/ui`. Los componentes de portada requieren un import explícito en ambos formatos.

## Avisos {#callouts}

Elige la variante adecuada. Las cinco usan los tokens del tema y admiten títulos propios.

<Tip title="Agrupa las instrucciones relacionadas">
  Coloca las indicaciones breves junto a la tarea.
</Tip>
<Info title="Salida estática">Ardo prerrenderiza las rutas durante el build de producción.</Info>
<Note title="Configuración opcional">
  El frontmatter puede cambiar el título y el orden en la barra lateral.
</Note>
<Warning title="Comprueba el destino">
  Revisa la ruta base antes de publicar un sitio versionado.
</Warning>
<Danger title="Ejemplo destructivo">
  Exporta tus datos antes de reemplazar un directorio con trabajo que quieras conservar.
</Danger>

```mdx
<Tip title="Keep related instructions together">Put the guidance next to the task.</Tip>
```

Estas variantes también existen como [alertas de GitHub](/es/guide/markdown#callouts) en Markdown simple.

## Tarjetas {#cards}

Usa tarjetas enlazadas para navegar y estáticas para resumir. La cuadrícula pasa a una columna en pantallas pequeñas.

<CardGroup cols={2}>
  <Card title="Primeros pasos" icon="Rocket" href="/es/guide/getting-started">
    Crea la documentación con un asistente o manualmente.
  </Card>
  <Card title="Configuración" icon="Settings" href="/es/guide/configuration">
    Configura rutas, referencia API, metadatos y salida.
  </Card>
  <Card title="Componentes locales" icon="Code">
    Importa componentes del proyecto o de un paquete instalado.
  </Card>
  <Card
    title="Código fuente"
    icon={<Github size={20} />}
    href="https://github.com/sebastian-software/ardo"
  >
    Examina la implementación y contribuye en GitHub.
  </Card>
</CardGroup>

```mdx
<CardGroup cols={2}>
  <Card title="Getting Started" icon="Rocket" href="/guide/getting-started">
    Set up a documentation site.
  </Card>
  <Card title="Local components" icon="Code">
    Import components into your MDX routes.
  </Card>
</CardGroup>
```

| Componente  | Prop        | Tipo                  | Uso                                                            |
| ----------- | ----------- | --------------------- | -------------------------------------------------------------- |
| `CardGroup` | `cols`      | `1 \| 2 \| 3 \| 4`    | Columnas preferidas en pantallas grandes. Predeterminado: `2`. |
| `CardGroup` | `children`  | `ReactNode`           | Tarjetas de la cuadrícula adaptable.                           |
| `Card`      | `title`     | `string`              | Título obligatorio.                                            |
| `Card`      | `href`      | `string`              | Destino interno o externo opcional. Hace clicable la tarjeta.  |
| `Card`      | `icon`      | `string \| ReactNode` | Nombre de icono registrado o contenido React.                  |
| `Card`      | `children`  | `ReactNode`           | Contenido de la tarjeta.                                       |
| `Card`      | `className` | `string`              | Clase CSS adicional.                                           |

```mdx
<Tabs defaultValue="pnpm">
  <TabList>
    <Tab value="pnpm">pnpm</Tab>
    <Tab value="npm">npm</Tab>
  </TabList>
  <TabPanels>
    <TabPanel value="pnpm">pnpm add ardo</TabPanel>
    <TabPanel value="npm">npm install ardo</TabPanel>
  </TabPanels>
</Tabs>
```

Si tus componentes crean pestañas internamente, define `defaultValue` en `Tabs` y valores `value` explícitos coincidentes en cada pareja de pestaña y panel.

| Componente | Prop           | Tipo        | Uso                                                                    |
| ---------- | -------------- | ----------- | ---------------------------------------------------------------------- |
| `Tabs`     | `defaultValue` | `string`    | Pestaña inicial. Predeterminado: la primera.                           |
| `Tabs`     | `children`     | `ReactNode` | `TabList` y `TabPanels` correspondientes.                              |
| `Tab`      | `value`        | `string`    | Valor estable asociado al `TabPanel`. Opcional si el orden es estable. |
| `Tab`      | `children`     | `ReactNode` | Etiqueta de la pestaña.                                                |
| `TabPanel` | `value`        | `string`    | Valor del contenido. Opcional si el orden coincide.                    |
| `TabPanel` | `children`     | `ReactNode` | Contenido del panel.                                                   |

## Bloques de código {#code-blocks}

El botón copia el código sin título ni números de línea. Los bloques Markdown se resaltan durante el build; `CodeBlock` también acepta una cadena directamente.

<GalleryPreview id="gallery-code" label="Ejemplo de código">
  <CodeBlock language="bash" title="terminal" code="pnpm add ardo" />
</GalleryPreview>

```mdx
<CodeBlock language="bash" title="terminal" code="pnpm add ardo" />
```

`CodeGroup` reúne fragmentos relacionados con sus nombres de archivo:

<GalleryPreview id="gallery-code-group" label="Ejemplo de grupo de código">
  <CodeGroup labels="Configuración,Ruta de inicio">
    <CodeBlock
      language="typescript"
      title="ardo.config.ts"
      code={
        'import { defineArdoConfig } from "ardo/config"\n\nexport default defineArdoConfig({ title: "My docs" })'
      }
    />
    <CodeBlock
      language="markdown"
      title="app/routes/home.md"
      code={"# Welcome\n\nStart with your first guide."}
    />
  </CodeGroup>
</GalleryPreview>

Los bloques Markdown admiten títulos, líneas destacadas, numeración y ajuste de prompts; consulta [Resaltado de sintaxis](/es/guide/markdown#syntax-highlighting).

### En rutas TSX {#in-tsx-routes}

Usa `ArdoCodeBlock` directamente en rutas `.tsx`. Escribe el código como contenido hijo, sin literales de plantilla ni escapes especiales:

```tsx
import { ArdoCodeBlock } from "ardo/ui"

export default function MyPage() {
  return (
    <ArdoCodeBlock language="tsx">
      export function Hello() {
        return <div>Hello world!</div>
      }
    </ArdoCodeBlock>
  )
}
```

El plugin `ardo:codeblock-highlight` procesa ArdoCodeBlock **antes del analizador JSX**. El contenido admite `<`, `{`, `>` y cualquier sintaxis. Se elimina la sangría común.

También funcionan la prop `code` y los literales de plantilla:

```tsx
<ArdoCodeBlock code="const x = 42" language="typescript" />
```

Si `language` es dinámico, se omite el resaltado del build y el código aparece como texto plano.

## Iconos {#icons}

Ardo incluye 50 iconos [Streamline Core Line](https://streamlinehq.com/icons/core-line). Comparten la cuadrícula 14×14, trazos redondeados y `currentColor` de los controles de navegación.

Los iconos registrados aparecen a 14 y 28 píxeles. Usa su nombre con `Icon` o importa el componente desde `ardo/icons`.

<GalleryIcons />

### Usar en MDX {#use-in-mdx}

Los 50 iconos Core están disponibles sin imports ni registro:

```mdx
<Icon name="Zap" size={20} />
<Card title="Deploy your site" icon="Rocket">
  Build the static output and publish it to your host.
</Card>
```

| Componente | Prop      | Tipo                           | Uso                                    |
| ---------- | --------- | ------------------------------ | -------------------------------------- |
| `Icon`     | `name`    | `string`                       | Nombre de icono registrado.            |
| `Icon`     | `size`    | `number`                       | Tamaño de visualización opcional.      |
| `Icon`     | SVG props | `SVGAttributes<SVGSVGElement>` | Se pasan al componente SVG registrado. |

### Usar en React {#use-in-react}

```tsx
import { BookOpen, Rocket, ShieldCheck } from "ardo/icons"

<BookOpen size={20} />
<Rocket size={28} className="launch-icon" />
<ShieldCheck size={20} aria-label="Security checks passed" />
```

El tamaño predeterminado es 24 px. `size` admite números o longitudes CSS; también puedes definir `width` y `height`. Los iconos heredan el color del texto y son decorativos por defecto. Añade `aria-label` o `aria-labelledby` si transmiten información sin texto.

`ArdoIcon` muestra un icono registrado por su nombre, por ejemplo en un enlace:

```tsx
import { ArdoIcon, ArdoLink } from "ardo/ui"

export function LaunchLink() {
  return (
    <ArdoLink to="/guide/getting-started">
      <ArdoIcon name="Rocket" aria-hidden /> Get started
    </ArdoLink>
  )
}
```

### Añadir o reemplazar iconos {#add-or-override-icons}

Registra otros componentes SVG de React e iconos de marca con `registerIcons()` en `app/root.tsx`:

```tsx
import { Github } from "ardo/icons"
import { registerIcons } from "ardo/ui"

registerIcons({ Github })
```

Después usa `<Icon name="Github" />` en MDX. Un nombre existente reemplaza su icono integrado. Declara otras bibliotecas como dependencias directas e impórtalas en el módulo de registro.

`getRegisteredIconNames()` devuelve los nombres integrados y propios para validar la configuración.

## Diseño y navegación {#layout-and-navigation}

Esta página muestra el diseño real: cabecera, secciones, barra lateral, migas, artículo, índice, acciones y pie. En pantallas pequeñas, abre el menú y el índice. Prueba la búsqueda y el tema en la cabecera.

[Diseño y navegación](/es/guide/layout-and-navigation) describe la composición y [Temas](/es/guide/theming) la paleta. Los ejemplos heredan los ajustes sin un tema de vista previa separado.
