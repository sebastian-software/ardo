# Releases

Ardo releases the framework, UI, and runtime as one package. This page keeps product claims grounded: what is ready to use today, what still evolves, and what is planned. The [changelog](https://github.com/sebastian-software/ardo/blob/main/packages/ardo/CHANGELOG.md) lists every release.

## Upgrade Guides

- [Upgrade to Ardo 6](/en/guide/releases/upgrade-to-v6) from Ardo 5: a static build without React Router, and fewer app files.
- [Upgrade to Ardo 5](/en/guide/releases/upgrade-to-v5) from Ardo 4: Ferromark for Markdown and MDX, and Ferriki for highlighting.
- [Upgrade to Ardo 4.0](/en/guide/releases/upgrade-to-v4) from Ardo 3: stable major-version URLs.
- [Migrate from TypeDoc](/en/guide/releases/migrate-from-typedoc): native API documentation replaces the `typedoc` option.

Coding agents follow the same guides through the [Agent Instructions](/en/guide/agent-instructions).

## Shipped

These capabilities are available in the current package line.

| Area                    | Notes                                                                                                                                                                    |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Static site build       | Vite build with static HTML for every page, file-based routes, and no client-side router.                                                                                |
| Markdown and MDX routes | Markdown, MDX, GFM, frontmatter, TOC extraction, and built-in MDX component mapping.                                                                                     |
| Syntax highlighting     | Build-time Ferriki highlighting for Markdown code fences and static `CodeBlock` usage.                                                                                   |
| Search                  | Generated search data with a built-in search UI.                                                                                                                         |
| Native API reference    | Configured with `api` in `ardo.config.ts` for TypeScript library APIs.                                                                                                   |
| Content collections     | Schema-validated local Markdown and MDX materialized as routes and typed static records for custom React views.                                                          |
| News and publications   | Repository-authored Markdown and MDX posts with shared authors, responsive images, and full-content Atom/RSS feeds; see [News and publications](/en/guide/publications). |
| Social metadata         | Generated canonical, Open Graph, and Twitter metadata for Markdown routes.                                                                                               |
| SEO build outputs       | Sitemap, robots output, LLM text artifacts, link checking, and static redirects.                                                                                         |
| Theme hue overrides     | Brand, accent, and neutral hues retint the default color ramp from the `ArdoRoot` theme prop or CSS.                                                                     |
| Components              | Callouts, badges, cards, tabs, accordions, steps, code blocks, icons, hero, and features, shown live on [Components](/en/guide/components).                              |

## Experimental

These areas work, but the API or maintenance story may still evolve.

| Area                  | Notes                                                                                                                                                                                                |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Native compiler SDK   | Pinned to a TypeScript 7.1 nightly; compiler compatibility and API stability require care.                                                                                                           |
| Theme token overrides | CSS variables and Vanilla Extract tokens are public, but the broader theming API and build-time customization story may still change.                                                                |
| Major docs versioning | Supports static major-version folders, root HTML redirects, `versions.json`, a version switcher at the end of the sidebar, and a banner on older versions.                                           |
| Static i18n           | Complete locale route trees, localized search and UI labels, alternate-language links, and build-time rejection of missing translations; see [Internationalization](/en/guide/internationalization). |
| Static OpenAPI        | Generates local OpenAPI 3.0/3.1 JSON or YAML reference pages; an interactive playground remains out of scope.                                                                                        |

## Not Planned

Ardo is intentionally not trying to become every kind of documentation product.

| Area                         | Reason                                                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Hosted editing workflow      | Ardo is repository-native and self-hosted. Teams that want hosted collaboration should use a hosted docs platform. |
| Built-in analytics product   | Static deployments can integrate analytics providers directly; Ardo does not need to own event storage.            |
| Lowest-JavaScript prose site | Ardo prioritizes React-native reuse. Astro, VitePress, or Starlight can be better for prose-only sites.            |
| TypeScript hover examples    | Twoslash-style hovers carry high maintenance and toolchain weight relative to their reach.                         |
| Embedded live playgrounds    | Sandpack-style editors conflict with Ardo's static-first, small-bundle output.                                     |
